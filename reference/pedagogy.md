# 教学设计规范

课件不是动画片。学生要**先想、再看、再解释**，并且看到"做错了会怎样"。以下规范来自 7 门课件的反复打磨。

## 1. 步骤（steps）
- 一步 = 一个可操作、可观察的动作。动词开头："点燃酒精灯，先预热""把蜡烛移到 20 cm 处"。
- 按教材规范顺序，安全要求放在对应步骤的 `warning` 里（不要堆在开头）。
- `observation` 写**学生应该看到什么**，用现象语言（"澄清石灰水变浑浊"），不要写结论。
- 一个步骤里有多个子动作时用 `actions`（如制作临时装片：擦 → 滴 → 撕 → 展 → 盖 → 染）。
- 每步给 `camera.focus`：镜头对准正在操作的部位。

## 2. 预测（predict）— 预测、观察、解释
- 在揭晓现象**之前**提问；问题针对本实验的关键现象或规律。
- 3 个选项：1 个正确 + 2 个来自**真实的错误观念**（不是凑数）。
  - 好：阶梯蜡烛"下层先灭 / 上层先灭 / 同时熄灭"。
  - 差："下层先灭 / 不会熄灭 / 变成蓝色"。
- `explain` 用一两句讲清"为什么"，联系第二视图（微观、光路、视野）。
- 每门课 ≥ 3 个，分布在前、中、后段。

## 3. "假如这样做"（mistakes）
- 选**学生真会犯、考试常考**的错误：先熄灭酒精灯（倒吸）、试管口未略向下倾斜（冷凝水倒流炸裂）、长颈漏斗未液封（漏气）、高倍镜用粗准焦（压碎玻片）、三心不同高（像不在光屏中央）。
- 后果演示要**看得见、看得懂**：镜头推近现象位置；现象夸张适度但方向正确；callout 一句话点明后果。
- `lesson`：一句话说清错在哪、正确做法是什么。
- 演示结束可倒带，状态完全恢复（校验器会检查）。
- 每门课 ≥ 3 个。有危险的错误（爆炸、炸裂）只做示意，不要血腥或恐吓。

## 4. 第二视图 — 看见看不见的
| 学科 | 第二视图 | 要点 |
|---|---|---|
| 化学 | 微观放大镜（粒子） | 宏观现象 ↔ 粒子变化 ↔ 化学方程式三者联动；原子守恒计数 |
| 物理（光学） | 光路图 | 特殊光线、实像实线、虚像虚线；随器材位置实时变化 |
| 物理（力/电） | 受力图 / 电路图 | 用 views 中的通用组件或自定义 2D canvas |
| 生物 | 显微镜视野 | 亮度、清晰度、倍数、倒像由状态实时决定 |

核心现象**全程可见**：第二视图浮窗不能太小（≥ 画布高度 55%），主镜头也要让人看清器材和操作位置。

## 5. 科学准确性
- 方程式、条件、气体符号、沉淀符号、配平都要对；中文化学式下标用 Unicode（CO₂、H₂O）。
- 数值用教材常用值（凸透镜 f = 10 cm、显微镜 10× 目镜）。
- 颜色要对：铜红色、氧化铜黑色、硫酸铜溶液蓝色、碘液染色细胞核棕黄色。
- 无色气体用半透明示意时注明"此处为示意"。
- 不确定的内容宁可简化，也不要编造。

## 6. 语言
- 面向学生：短句、口语、具体；术语首次出现时带解释。
- 按钮文字 ≤ 12 字，动词开头。
- 年级适配：初中不出现超纲公式（如透镜公式只在内部计算，界面用规律表）。

## 7. 时长
- 一门课 6–10 分钟：步骤 6–10 个，每步演示 2–6 秒。
