# 视觉自查清单

能看图或打开浏览器时，逐条检查（运行时提供 `window.__xiaokeLab.capture()` 截取 3D 画面、`framing()` 返回取景数据、`state()` 返回课件状态）。

## 取景
- [ ] 主装置占第二视图浮窗以外可用区域的大部分（`framing().widthRatio` 在 0.78–0.86）。
- [ ] 浮窗、按钮、callout 没有压住器材。
- [ ] 关键部位（加热处、液面、光屏、载物台）没有被切出画面。

## 器材
- [ ] 没有悬空物体：工具不用时放在台面或支架上。
- [ ] 连接正确：导管插进塞子、伸入液面；塞子塞在瓶口；夹子夹在试管上部约 1/3 处。
- [ ] 比例合理：试管与烧杯、酒精灯与铁架台大小关系可信。
- [ ] 颜色与材质正确（玻璃透明可见、金属反光、液体颜色符合化学事实）。

## 真实感（详见 `realism.md`）
- [ ] 火焰在灯芯正上方、外焰碰到被加热部位，颜色与燃料相符（酒精灯黄、CO/H₂ 淡蓝）。
- [ ] 试剂颜色与化学事实一致；无色液体没有被染色，但能看出液面和液体体积。
- [ ] 高画质下玻璃有高光和折射，器材在台面上有阴影；透过玻璃看不到锯齿或破面。
- [ ] 变色、沉淀、气泡是渐进的，并从正确位置开始。

## 现象与演示
- [ ] 每一步的现象在画面中清楚可见（不只是 callout 文字）。
- [ ] "假如"演示镜头**推近**，后果在 3D 中看得见；倒带后恢复原状。
- [ ] 第二视图内容随状态实时变化，没有像素块，核心现象全程可见。

## 界面
- [ ] 文字不截断、不重叠；手机横屏（约 844×390）与电脑宽屏（1440×900）都正常。
- [ ] 竖屏手机出现横屏提示；全屏按钮可用。

做不到视觉检查时，在交付说明里列出请老师重点看的 2–3 处。

## 离线预览（不需要浏览器）

在 Skill 根目录使用 Node.js（零依赖）：

```sh
node scripts/validate-course.mjs course.js
node scripts/preview-course.mjs course.js --step 1 --out preview.png
node scripts/preview-course.mjs course.js --all --out preview.png
node scripts/preview-course.mjs course.js --mistake branch-id --out branch.png
```

步骤从 1 编号；`--all` 写出 `preview-01.png`、`preview-02.png` 等。配置有额外文件时，校验和预览均可重复传入 `--include extra.js`，路径相对课件配置所在目录。打开每一步图片检查并修正后再交付。主图是 1000×600 的相机近似画面；下方是正交俯视、侧视，侧视棕线为台面；蓝色为第二视图保留区，棕色为操作面板保留区，红十字是该步焦点。预览会近似绘制透明玻璃、液体、内置微观粒子、DataTexture 与 custom2d 的线条和形状；中文显示为占位框，光照和最终网页界面仍不保证一致，不能替代真实渲染检查。`--mistake` 生成 `branch-middle.png` 与 `branch-end.png`，中间帧选取距离动画总时长中点最近的补间中点；没有补间时用分支起点。包围盒也不能可靠表达空心容器或细长曲线，检查器报告仅供定位。

主图顶部 W / H 是主装置簇投影占扣除面板和第二视图后的可用区域的宽 / 高百分比。目标为 60%–85%；低于 60% 警告、低于 45% 错误；完整装置超过 90% 或被边缘、保留区裁切时警告。邻近器材及大小相近的对照装置参与计算，远处小道具不应当撑大主装置占比。可设置 `framingApparatus`、收拢布局；不要通过排除装置部件或过度放大来消除警告。复杂分离结构仍须人工核对。

检查器会逐步警告悬空、包围盒大幅相交、缺少锚点、尺寸异常和焦点落入保留区；非常明显的悬空为错误。确实需要的嵌套或支撑关系可在器材对象上设置 `item.contains = ['child-id']` 或 `item.mountedOn = 'support-id'`（也支持数组和 `item.object.userData` 对应字段）。这只表示关系，不能代替目视检查；不要为了消除警告而虚报支撑。`minimums:false` 仅供简单演示课关闭 6 步、3 预测、3 假如的最低数量要求，预测仍须有至少三个选项和非空解释。

经核查确认是包围盒误报时，可在配置中写 `geometryExceptions: [{kind:'overlap', ids:['stand','lamp'], reason:'支架空心，包围盒与灯重叠'}]`；合理的细长器材可用 `{kind:'scale', ids:['rail'], reason:'光具座为细长导轨'}`。每条必须写明原因，不能用来掩盖真实碰撞；它只确认对应警告，不会屏蔽严重错误，仍需视觉复核。
