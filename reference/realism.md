# 真实感：让课件像一间真的实验室

老师一眼就能看出"这不像真的"。真实感不靠堆特效，靠四件事都对：**器材像、摆放对、现象准、画面有层次**。写配置前先读这一页，写完对照文末清单。

## 1. 器材：按实物比例和连接方式搭

- **比例以实物为准。** 先查器材库（`apparatus.md`）里的默认尺寸，不要随手缩放。常见参照（实物）：试管 Φ18×180 mm，酒精灯高约 80 mm、火焰高 30–40 mm，100 mL 烧杯高约 70 mm，铁架台立杆约 600 mm，集气瓶 125 mL 高约 110 mm。同一画面里的相对大小要和这些比例一致；一个器材放大了，和它相连的都要一起核对。
- **连接要"真的接上"。** 导管穿过塞子并露出一小段；塞子塞进瓶口约 1/2–2/3；铁夹夹在试管距管口约 1/3 处；导管口伸到液面下或集气瓶底部该到的位置。用锚点和世界坐标对齐，不靠目测数字。
- **加热位置正确。** 火焰外焰接触被加热部位：`flame` 默认高度已按酒精灯高度的 55% 设定，摆放时让被加热点落在火焰高度的 80%–100% 处，并且就在灯芯正上方。固体加热时试管口略向下倾斜，液体加热时试管与桌面约成 45°、液体不超过容积 1/3。
- **器材库里没有的器材要认真建模**（见 `custom-apparatus.md`）：旋转体用 `build.lathe` 且不少于 48 段；玻璃壁要有厚度（内外两条轮廓）；转角处加一小段倒角，硬直角透过玻璃看会出现锯齿。不用方块和球凑数。
- **不用的工具有地方放。** 药匙、镊子、玻璃片放在台面或托盘里；灯帽取下后扣放在灯旁；火柴用后放进废物缸。

## 2. 材质与颜色：以化学事实为准

| 物质 | 真实外观 | 常见错误 |
|---|---|---|
| 澄清石灰水、稀盐酸、稀硫酸、蒸馏水 | 无色透明 | 画成乳白或淡蓝色 |
| 硫酸铜溶液 | 蓝色，浓度越大越深 | 画成绿色 |
| 高锰酸钾 | 固体暗紫色（近黑），溶液紫红色 | 固体画成鲜紫色 |
| 氧化铜 / 木炭粉 / 二氧化锰 | 黑色粉末 | 三者画得一模一样又不加标注 |
| 铜 | 紫红色，有金属光泽 | 画成橙色或金黄色 |
| 铁锈 / 氧化铁 | 红棕色 | 画成鲜红色 |
| 石蕊溶液 | 紫色；遇酸变红，遇碱变蓝 | 初始就画成红色 |
| 酚酞溶液 | 无色；遇碱变红 | 初始画成粉色 |
| 碳酸钙沉淀、氢氧化镁 | 白色浑浊 | 画成透明 |
| 氢氧化铜沉淀 | 蓝色絮状 | 画成溶液一样均匀的蓝 |

- 无色液体交给器材库自带的液体（自定义器材用 `build.liquidMaterial()`），不要自己调成"看得见的蓝色"。高画质下液体会略带水色并有反光液面，足够辨认。
- 颜色变化要**渐变**（见 `effects.md` 的 `dyeSpread`、`turbidity`、`powderBed`），并且从发生反应的位置开始：沉淀从导管口附近出现，粉末从受热最强处先变色。
- 金属用 `build.metalMaterial()`，橡胶塞是哑光深色，木质器材（试管夹、木条）不反光。

## 3. 现象：准确、有先后、看得见

- **火焰颜色按燃料选。** 酒精灯用默认 `flame()`（底部蓝、主体黄）；一氧化碳、氢气、甲烷在尖嘴处燃烧用 `flame({gas:true})`（淡蓝色）；酒精喷灯用 `flame({torch:true})`。硫在空气中是微弱的淡蓝色、在氧气中是明亮的蓝紫色；铁丝在氧气中火星四射、不是火焰；镁条是耀眼白光。
- **气泡有节奏。** 开始加热时导管口先冒出少量、不连续的气泡（装置里的空气），之后才连续均匀；排水法收集要等连续均匀后再收集，这本身就是一个好的预测题。
- **先后顺序符合实际。** 先预热再集中加热；先撤导管再熄灯；反应需要时间时用补间表现"逐渐"，不要一步到位。
- **每个现象都要在三维画面里看得见**，不能只靠文字气泡说明。镜头推到现象发生处，占画面足够大。
- **第二视图和宏观现象同步。** 粒子重组、光路、显微视野的变化要和主画面的进度用同一个进度变量驱动。
- 不夸张：不加现实中没有的发光、爆炸、彩色烟雾。危险后果演示（倒吸、炸裂）只在"假如这样做"里出现，并写明是模拟。

## 4. 画面：有层次、有焦点

- 运行时默认以**高画质**打开：玻璃有折射和高光、器材有柔和阴影、火焰会照亮附近器材。帧率持续过低时会自动降到标准画质，右上角"画质"按钮可以手动切换。只有明确面向低端设备时，才在配置里写 `quality: 'standard'`。
- 主装置占可用区域 60%–85%，四周留一点空；关键步骤和后果演示用特写（`camera.focus`）。
- 玻璃器材不要互相完全遮挡；需要读数的刻度、液面朝向镜头。
- 一个画面只突出一个现象。同时发生的次要变化可以保留，但不要抢镜头。

## 交付前的真实感清单

- [ ] 器材之间的相对大小和实物一致，连接处没有缝隙、穿模或悬空。
- [ ] 火焰在灯芯正上方，外焰碰到被加热部位；火焰颜色与燃料相符。
- [ ] 每种试剂的颜色、状态与上表或教材一致；无色液体没有被染色。
- [ ] 颜色、沉淀、气泡的变化是渐进的，并从正确的位置开始。
- [ ] 操作顺序与真实实验一致（预热、撤导管、熄灯、验纯等）。
- [ ] 每一步的现象在三维画面里清楚可见，第二视图与之同步。
- [ ] 打开 HTML 在高画质下看过一遍（做不到就在交付说明里写明没有看过）。
